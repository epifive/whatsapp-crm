# Changelog

## 1.0.0 — initial release

- WhatsApp: official Cloud API and QR (Baileys) connections per number, with the anti-ban engine (warm-up, pacing, daily limits, spintax, opt-outs) on QR numbers.
- Realtime team inbox: assignment, notes, tags, quick replies, media, receipts, typing/viewing indicators, 24-hour window and templates.
- CRM: contacts with custom fields, CSV import/export, segments, consent, deal pipelines, tasks with reminders, timelines.
- Templates (sync, create, submit) and campaigns with scheduling, throttling and live reports.
- Chatbot flow builder with menus, questions, conditions, delays, CRM actions, webhooks and AI replies.
- AI assistant on each workspace's own OpenAI, Gemini or Claude key: suggestions, rewrite, translation, summaries, auto-replies from a knowledge base.
- REST API with API keys and signed outbound webhooks.
- SaaS billing: plans with limits and features, trials, grace period, Stripe / Razorpay / PayPal / bank transfer, coupons, tax and invoices.
- Super-admin panel: workspaces (assign plans, suspend, view as owner), plans, coupons, invoices, branding, SMTP, email templates.
- Web installer, demo data, a live demo mode (one-click demo accounts, automatic resets), Docker Compose and PM2 setups, HTML documentation.
